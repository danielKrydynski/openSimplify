# OpenSimplify Chrome Extension (Manifest V3)

A free, open-source, privacy-first job application autofill and AI copilot for Workday, Greenhouse, Lever, Ashby, and LinkedIn.

## 🚀 30-Second Installation Guide

1. **Unzip this folder** (e.g. to `Desktop/opensimplify-extension` or `Downloads/opensimplify-extension`).
2. Open Google Chrome (or Brave, Edge, Arc) and navigate to:
   ```
   chrome://extensions
   ```
3. In the top right corner, turn **ON** the **Developer mode** toggle.
4. In the top left, click **"Load unpacked"**.
5. Select this unzipped `opensimplify-extension` folder.
6. Done! You will see the **OpenSimplify** icon in your Chrome toolbar.

---

## ⚡ How to Use on Job Applications

1. Open any job application page on:
   - **Greenhouse** (`boards.greenhouse.io/*`)
   - **Lever** (`jobs.lever.co/*`)
   - **Workday** (`*.myworkdayjobs.com/*`)
   - **Ashby** (`jobs.ashbyhq.com/*`)
   - **LinkedIn** Easy Apply
   - Or any standard application form
2. Look for the floating **⚡ OpenSimplify** button in the bottom-right corner.
3. Click it to open the in-tab copilot drawer, or click **"Autofill This Application"**.
4. Use the **AI Question Solver** to draft STAR-method responses for custom essay prompts directly inside the same tab!

---

## 🔒 100% Privacy Guarantee
- No telemetry or external tracking.
- All profile data stays in your local browser storage.
- LLM requests go directly to your chosen local daemon (Ollama, LM Studio) or your configured cloud gateway.
